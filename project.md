# School — 400 level, first semester

Nine courses, one timetable, ends 20 December 2026. What I hand over: passed courses.

## Courses

Each course is its own project in `projects/`. Their notes, handouts and assignments
live in each course's `files/`.

## Where things go

- Timetable: `files/MY_TIMETABLE.md`
- Student info (matric number, level, dept): `files/student-info.md`
- Class notes: `projects/<course>/files/notes-YYYY-MM-DD.md`
- Assignments and lecturer announcements: the course's own `files/`

## Note-taking rule

For notes: write exactly what I say. Only fix typos and grammar, and format in
markdown. Nothing else. No added facts, examples, or sections I did not give.
