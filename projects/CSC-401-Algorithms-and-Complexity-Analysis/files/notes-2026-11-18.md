## Review Question: Time Complexity of a Nested Loop

The question is a sum built inside two `for` loops:

```java
int sum = 0;

for (int j = 0; j < n; j++) {
    for (int k = 0; k < n; k++) {
        sum += j + k;
    }
}
```

### The rule for nested loops

Count the outer loop, count the inner loop, multiply them.

- Outer loop `j` runs `n` times.
- Inner loop `k` runs `n` times for every single pass of the outer loop.
- Total: `n × n = n²`.

So the time complexity is **O(n²)**.

### Why the constant does not matter

The body `sum += j + k` is one addition and one assignment — constant work, so it
contributes nothing to the growth rate. Only the loop bounds decide the order.

### If the inner loop depends on the outer loop

A common version writes the inner bound as `j` instead of `n`:

```java
int sum = 0;

for (int j = 0; j < n; j++) {
    for (int k = 0; k < j; k++) {
        sum += j + k;
    }
}
```

Here the inner loop runs `j` times on each pass, so the total is:

```
0 + 1 + 2 + ... + (n - 1) = n(n - 1) / 2
```

That is `(n² - n) / 2`, and the dominant term is still `n²`. So this version is also **O(n²)**.

### The two answers to remember

| Shape of the loops | Total work | Time complexity |
| --- | --- | --- |
| Inner loop runs `n` times each pass | n × n | O(n²) |
| Inner loop runs `j` times each pass | n(n − 1) / 2 | O(n²) |

Either way a loop inside a loop, with both bounds tied to `n`, is **O(n²)**.

## Worked Example: Line-by-Line Cost of `DuplicateAnalyzer`

Cost of every line, written as a comment beside it:

```java
public class DuplicateAnalyzer {

    public static void analyzeDuplicates(int[] data) {   // O(1) — called once
        int n = data.length;                             // O(1)
        int duplicateCount = 0;                          // O(1)
        boolean hasDuplicates = false;                   // O(1)

        System.out.println("Starting scan...");          // O(1)

        // First block: Sequential pass to print elements
        for (int idx = 0; idx < n; idx++) {              // O(n) — n + 1 checks, n passes
            System.out.print(data[idx] + " ");           // O(1) each, n times → O(n)
        }
        System.out.println();                            // O(1)

        // Second block: Nested loops to compare every pair
        for (int i = 0; i < n; i++) {                    // O(n) — n + 1 checks, n passes
            int current = data[i];                       // O(1) each, n times → O(n)

            for (int j = i + 1; j < n; j++) {            // O(n²) — n(n−1)/2 passes
                int candidate = data[j];                 // O(1) each → O(n²) total

                if (current == candidate) {              // O(1) each → O(n²) total
                    duplicateCount++;                    // O(1) each → O(n²) worst case
                    hasDuplicates = true;                // O(1) each → O(n²) worst case
                    System.out.println("Match: " + current);  // O(1) each → O(n²) worst case
                }                                        // O(1)
            }                                            // O(n) — loop closes
        }                                                // O(n) — loop closes

        // Third block: Final summary output
        if (hasDuplicates) {                             // O(1)
            System.out.println("Total matches: " + duplicateCount);  // O(1) — runs 0 or 1 time
        } else {                                         // O(1)
            System.out.println("All elements are unique");           // O(1) — runs 0 or 1 time
        }                                                // O(1)
    }                                                    // O(1)
}                                                        // O(1)
```

Totals:

- **Block 1:** O(1) + O(n) + O(n) + O(1) = **O(n)**.
- **Block 2:** outer O(n), inner n(n−1)/2 passes = **O(n²)**.
- **Block 3:** **O(1)**.

Whole program: O(1) + O(n) + O(n²) + O(1) = **O(n²)** time, **O(1)** extra space.
The inner loop starting at `i + 1` gives the same triangular shape as the review question:
n(n − 1)/2 pairs, still O(n²).
