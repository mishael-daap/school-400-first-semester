## System Components

- A system has different components.

### Entity

- An entity is an object of interest in the system.
- Example: customers at a bank.

### Attribute

- An attribute is a property of an entity.

### Activity

- An activity is a time period of specified length.
- It is made up of operations that transform the state of an entity.

### Event

- An event is an instantaneous occurrence that changes the state of the system.

### State Variables

- State variables are variables that define the state of the system at any time.
- They contain enough information to restart a simulation from that point.

### Process

- A process is a sequence of events ordered in time.

## Example

| System | Entities | Attributes | Activities |
| --- | --- | --- | --- |
| Banking | Arrival, departure | Username and account number | Withdrawal and deposit |

## Reasons for Simulation

- The real system is too difficult, risky or expensive to observe.
- Parts of it cannot be observed.
- Analyse a system before it is built.
- Reduce the number of design errors.

## Why Do We Need Simulation

- Optimise a design to improve behaviour.
- Analyse systems already in operation.
- Create virtual environments for training and entertainment.
- Minimise production risk.

## Performance Evaluation

- Performance evaluation is how we find out if a system is doing well.
