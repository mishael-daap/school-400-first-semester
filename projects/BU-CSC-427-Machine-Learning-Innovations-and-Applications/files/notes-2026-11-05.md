## Types of Machine Learning

- Supervised learning
- Unsupervised learning
- Semi-supervised learning
- Reinforcement learning

## Supervised Learning

Machine learning algorithms that learn from input and output pairs are called supervised machine learning algorithms.

Example: identifying the zip code from handwritten digits on an envelope.

Another example: determine whether a tumour is benign based on a medical image.

## Types of Supervised Machine Learning Problems

- Classification
- Regression

### Classification

The goal in classification is to predict a class label, which is chosen from a predefined list of possibilities.

Classification is sometimes separated into binary classification and multi-class classification.

#### Binary Classification

Binary classification is the special case of distinguishing between exactly two classes. It can be thought of as trying to answer a yes or no question.

One example is classifying emails as either spam or not spam.

#### Multi-class Classification

This is classification with more than two classes.

Examples:

- Classifying the iris
- Predicting what language a website is in from the text on the website

### Regression

The goal is to predict a continuous number or a floating point number.

Examples:

- Predicting a person's annual income from their education, their age and where they live
- Predicting income

## Underfitting, Overfitting and Generalization

**Generalization**: a model built on the training data and then used to make accurate predictions on new, unseen data that has the same characteristics generalizes.

**Overfitting**: building a model that is too complex for the amount of information available is called overfitting.

**Underfitting**: if a model is too simple, it may not be able to capture all the aspects of the variability of the data, and the model will perform poorly even on the training set.

## K-Nearest Neighbors

There are two important parameters to the k-neighbors classifier: the number of neighbors, and how you measure distance between data points.

- **Strength**: the model is easy to understand and often gives reasonable performance without a lot of adjustments.
- **Weakness**: when the training set is very large, predictions can be slow, and it does not perform well on data sets with many features.

Nearest neighbors: for small data sets, good as a baseline.

## Unsupervised Learning

In unsupervised learning the algorithm is just shown the input data and asked to extract knowledge from this data. Unsupervised learning includes all kinds of machine learning where there is no known output.

Challenges in unsupervised learning: evaluating whether the model learned something useful.

- They are applied to data that does not contain any labelled information, so we do not know what the right output should be.
- They are mostly used in an exploratory setting, when the data scientist wants to understand the data better.
- Another application is as a preprocessing step for supervised algorithms.

## Preprocessing and Scaling

Scaling methods do not make use of supervised learning, which makes them unsupervised.

## Types of Unsupervised Learning

- Transformations of the dataset
- Clustering

### Unsupervised Transformations of a Dataset

Algorithms that create a new representation of the data, which might be easier for humans or other machine learning algorithms to understand compared to the other representation.

### Clustering

Partition data into distinct groups of similar items.

## Dimensionality Reduction

This is transforming data using unsupervised learning.

- **Principal Component Analysis (PCA)**: rotates the dataset in a way such that the rotated features are statistically uncorrelated.
- **Non-negative Matrix Factorization (NMF)**: aims to extract useful features by decomposing the data into non-negative components.
- **K-means clustering**: partitions the data into `k` groups by assigning each point to the nearest cluster centre and repeatedly updating the centres.
- **DBSCAN**: density-based clustering — groups points that are packed closely together and marks isolated points as noise. Unlike k-means, the number of clusters does not have to be given in advance.

## Comparison: Supervised vs Unsupervised vs Semi-supervised Learning

| | Supervised | Unsupervised | Semi-supervised |
| --- | --- | --- | --- |
| **Data used** | Labelled input and output pairs | Unlabelled data only | A small labelled set plus a large unlabelled set |
| **Goal** | Learn a mapping from input to output | Extract structure or knowledge from the data | Use the few labels to guide learning over the much larger unlabelled data |
| **Typical tasks** | Classification, regression | Clustering, dimensionality reduction, preprocessing | Classification where labels are scarce or expensive |
| **Evaluation** | Straightforward — compare predictions with known labels | Difficult — there is no known output to compare against | Compare against the labelled test set |
| **Example** | Spam vs not spam; predicting income | Customer segmentation; PCA | Medical images, where only a few scans have been labelled |
