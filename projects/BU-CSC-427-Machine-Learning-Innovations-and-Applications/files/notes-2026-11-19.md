## Class Exercise: Eight Problems

### 1. Task, performance and experience

| Problem | Task | Performance | Experience |
| --- | --- | --- | --- |
| Email spam protection | Mark each email spam or not spam | Precision and recall — a false positive loses a real email | Labelled emails, text plus sender metadata |
| Student performance prediction | Predict a student's final score | RMSE or MAE against the real score | Past student records: grades, attendance, course load |
| Fruit classification | Name the fruit in an image | Accuracy, top-1 | Labelled fruit images |
| Customer churn prediction | Predict whether a customer will leave | Precision and recall, AUC because churn is rare | Customer history: usage, tenure, complaints |
| Credit card fraud detection | Flag a transaction as fraud or genuine | Recall first, then precision — missing fraud costs more | Labelled transaction records |
| Plant disease classification | Name the disease in a leaf image | Accuracy per class | Labelled leaf images |
| Online predator detection | Mark a conversation as predatory or safe | Recall first — missing a predator is the bad error | Labelled chat conversations |
| Facial emotion recognition | Read the emotion on a face | Accuracy across the emotion classes | Labelled face images |

### 2. Type of machine learning

All eight are **supervised**, because each one learns from examples that already carry the right answer. The model sees input and label pairs and is judged on how well it reproduces the label.

The exceptions worth naming:

- **Student performance** drops to **unsupervised** if nobody has recorded final scores — then I'd cluster students on behaviour instead.
- **Customer churn** also drops to unsupervised when churn labels are missing or late.
- **Credit card fraud** is often run as **anomaly detection**, which is unsupervised, because real fraud labels are few and arrive months late.

### 3. Classification or regression

**Classification** for seven of them: spam, fruit, churn, fraud, plant disease, predator detection and emotion. In each case the output is a label from a fixed set — spam or not, fraud or genuine, happy or sad.

**Regression** for student performance, but only if the target is the actual numeric score. The model then predicts a number on a continuous scale, so RMSE and MAE make sense. If the target is pass or fail, the same problem becomes classification.

The test I use: does the answer come from a list, or is it any number on a scale? List means classification, scale means regression.

### 4. Type of data

- **Email spam:** unstructured text, plus structured metadata like sender and time.
- **Student performance:** structured and tabular — a CSV of grades, attendance and course load.
- **Fruit classification:** unstructured image data.
- **Customer churn:** structured, tabular customer records.
- **Credit card fraud:** structured transaction rows, with timestamps and amounts.
- **Plant disease:** unstructured image data.
- **Online predator detection:** unstructured text, the chat logs themselves.
- **Facial emotion recognition:** unstructured image data, and video or audio if the model reads the whole face in motion.

Next: the two I'd argue about in the exam are student performance and churn, because both flip between classification and regression, or supervised and unsupervised, depending on how the target is defined.
