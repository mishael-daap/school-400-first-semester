## Question

A Book has two chapters, with number of pages as 20 and 30 for the two chapters respectively. Create a Python class known as `BigBook`, with two fields as number of pages in each of the chapters (`Chap1Pg` and `Chap2Pg`) each of them assigned requisite initial values. The methods of the class are `ReadBook` and `SummarizeBook`. These methods simply display the messages "I Can Read" and "I Can Summarize" respectively. Instantiate the class to form an object called `PracticalBook`. Invoke the two methods and print the number of pages in Chapter 1 and Chapter 2 of the practical book.

## Solution

```python
class BigBook:
    def __init__(self):
        self.Chap1Pg = 20          # pages in chapter 1
        self.Chap2Pg = 30          # pages in chapter 2

    def ReadBook(self):
        print("I Can Read")

    def SummarizeBook(self):
        print("I Can Summarize")


# instantiate the class
PracticalBook = BigBook()

# invoke the two methods
PracticalBook.ReadBook()
PracticalBook.SummarizeBook()

# print the number of pages in each chapter
print("Chapter 1 has", PracticalBook.Chap1Pg, "pages")
print("Chapter 2 has", PracticalBook.Chap2Pg, "pages")
```

## Output

```
I Can Read
I Can Summarize
Chapter 1 has 20 pages
Chapter 2 has 30 pages
```
