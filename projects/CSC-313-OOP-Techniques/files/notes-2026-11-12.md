## Inheritance

- Inheritance allows a programmer to define a class that inherits the properties and methods of another class.
- Child class — also called the **derived class**.
- Parent class — also called the **base class**.


## Task: Classes `Sun` and `Moon`

A Python program is made up of two classes, `Sun` and `Moon`. Create the two classes and write a statement to show that `Moon` inherits from `Sun`. The constructor method should be populated with a `pass` statement.

```python
class Sun:
    def __init__(self):
        pass


class Moon(Sun):          # Moon inherits from Sun
    def __init__(self):
        pass


moon = Moon()
print(issubclass(Moon, Sun))   # True  -> Moon is a subclass of Sun
print(isinstance(moon, Sun))   # True  -> moon object is also a Sun
```

- `class Moon(Sun):` is the inheritance statement — the parent class goes in the brackets.
- `pass` does nothing; it is there so the constructor body is not empty (Python needs at least one line).
## Task: Classes `Goodman` and `FatherChristmas`

A class `Goodman` and a class `FatherChristmas`. `FatherChristmas` inherits from `Goodman`. Express this in Python.

```python
class Goodman:
    def __init__(self):
        pass


class FatherChristmas(Goodman):    # FatherChristmas inherits from Goodman
    def __init__(self):
        pass


father_christmas = FatherChristmas()
print(issubclass(FatherChristmas, Goodman))   # True
print(isinstance(father_christmas, Goodman))  # True
```

- `Goodman` is the parent (base) class; `FatherChristmas` is the child (derived) class.
