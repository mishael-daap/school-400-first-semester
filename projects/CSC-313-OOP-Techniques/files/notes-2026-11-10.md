## Task: Class `marriageType`

Create a class called `marriageType` with the attributes:

| Attribute | Value |
| --- | --- |
| `num_wives` | initial value of 1 |
| `place_of_marriage` | mosque, church, shrine (enum — any one can be chosen) |
| `marriage_name` | polygamy, monogamy |

Create an object called `mono_marriage` and instantiate it from the class `marriageType`.

Create two methods:

- `marriageDance()` — explains the type of dance at the wedding.
- `marriageSong()` — explains the type of song played at the wedding.

Both are print statements.

```java
enum PlaceOfMarriage { MOSQUE, CHURCH, SHRINE }

class MarriageType {
    int numWives = 1;                       // initial value of 1
    PlaceOfMarriage placeOfMarriage;
    String marriageName;

    // parameterized constructor
    MarriageType(String marriageName, PlaceOfMarriage placeOfMarriage) {
        this.marriageName = marriageName;
        this.placeOfMarriage = placeOfMarriage;
    }

    void marriageDance() {
        if (marriageName.equals("monogamy"))
            System.out.println("Monogamy: the couple dances alone, one partner each.");
        else
            System.out.println("Polygamy: the husband dances with all his wives.");
    }

    void marriageSong() {
        if (marriageName.equals("monogamy"))
            System.out.println("Monogamy: one love song is played for the one wife.");
        else
            System.out.println("Polygamy: a song is played for each wife in turn.");
    }
}

class Main {
    public static void main(String[] args) {
        MarriageType monoMarriage =
            new MarriageType("monogamy", PlaceOfMarriage.CHURCH);
        monoMarriage.marriageDance();
        monoMarriage.marriageSong();
    }
}
```

## Constructors

- A constructor is a special method used for initializing the instance variables during object creation.
- There are three types: parameterized, non-parameterized, and default constructors.
