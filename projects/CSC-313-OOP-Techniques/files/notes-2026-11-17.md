## Creating Class Attributes at Runtime

`setattr` is used to set the named attribute on the given object with a specified value at run time.

```python
# Program to Create Class Attributes at Run Time
class Country:
    pass

empl = Country()
setattr(empl, 'Area', 90000)

emp2 = Country()
setattr(emp2, 'Location', 125)

print(empl.Area)
```

Outcome on the slide:

```
class Country:
    Area = 90000
    Location = 125
```

To complete the exercise, add `print(emp2.Location)` and run it:

```
90000
125
```
